Why switch

Switching does not hurt

Repository paths, Docker port connectors and the credential model follow Nexus conventions. A production cut-over ran on the same host and the same ports without changing one line of CI configuration.

It is small

A single Go binary. No JVM, no plugins, no application server. It starts serving in seconds and runs in a few hundred megabytes under real CI load.

Still shipping when upstream is down

Cached artefacts keep being served while a public registry is unreachable, so a bad afternoon at Maven Central does not stop your builds.

Nothing held back for a paid tier

There is no paid tier. Apache 2.0, every feature, no component limits, no request quotas.

Running in one command

$ docker compose -f deploy/docker-compose.yml up -d

Then open http://localhost:8081/ui/. Point your clients at it exactly as you would at Nexus:

mvnMavensettings.xml
<mirror>
  <id>holiaokho</id>
  <url>http://localhost:8081/repository/maven-public/</url>
  <mirrorOf>*</mirrorOf>
</mirror>
npmnpm.npmrc
npm config set registry http://localhost:8081/repository/npm-group/
dkrDockerdocker pull
docker pull localhost:8081/docker-hub/alpine:3.19

Configuration

A working configuration is this short. Every key can be given as a HOLIAOKHO_* environment variable instead, which is usually what you want in a container.

server:
  listen: ":8081"
database:
  url: "postgres://holiaokho:PASSWORD@localhost:5432/holiaokho?sslmode=disable"
storage:
  type: fs              # fs | s3
  path: ./data/blobs
auth:
  anonymous_enabled: true
  session_ttl: 30m
log:
  level: info

Where the name comes from

In Taiwanese Hokkien, hó-liāu（好料）means good stuff — good ingredients, good material, the kind you bring out when guests arrive. Khòo（庫）is where you keep things. Together: the place the good stuff lives.

The packages your builds depend on, and the artefacts they produce, are exactly that. They deserve somewhere dependable and close to hand.

The mark is a 广 roof with goods stacked beneath it — a storehouse, with the amber line for the light left on.
